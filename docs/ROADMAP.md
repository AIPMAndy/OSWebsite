# OSWebsite — Product Roadmap

> 这是计划，不是当前已发布功能。按证据验证，每个版本均要求可运行、可复现、可撤销。

## v1.0 — Core Simulator ✅

- 五种主题、五种设备外壳、统一应用内容。
- 原生 JS 窗口管理 + 移动端全屏应用。
- 11 个演示/可用应用；笔记与看板支持本地数据。
- 命令面板、简单终端、静态部署、配置文件、导入导出 JSON。
- 演示数据明确标注；无虚假实时指标。

## v1.1 — Creator Site Builder（候选）

- 站点访客模式一键设为默认；免编程导出生产包。
- Markdown 内容编辑与存储；链接 / 项目 / 页面排序、图片上传。
- 主题令牌与组件样式可视化编辑。
- 分享 URL 直达具体应用与项目。
- 可访问性：键盘操作、触屏拖拽、屏幕阅读器、对比度、减弱动画。
- 全自动 Playwright CI、视觉回归测试与 Lighthouse 基线。

## v1.2 — App Platform（候选）

- 插件开发 SDK：manifest、注册、权限清单、沙箱 iframe、生命周期。
- 公开应用模板与示例；插件签名/版本管理。
- 多工作区、用户模板一键切换、开放第三方主题。

## v2.0 — AI Website OS（探索，不承诺）

- AI 指令生成站点配置 / 页面，并支持变更预览和回滚。
- 用用户授权的 GitHub API 同步公开仓库元数据；明确缓存与同步状态。
- BYOK AI 服务，可选边界与成本上限。
- 自托管的访客分析与在线协作模块（隐私优先，明确知情同意）。

## 衡量比竞品更高级的指标（建议验收基线）

1. 设备外壳数 ≥5，主题数 ≥5；同一内容完全复用。
2. 手机与电脑无核心内容缺失；宽度 360px 至 1440px 可用。
3. 11 个内置应用都能打开；笔记 / 看板持久化经过自动测试。
4. `npm test` 全绿；完整浏览器 E2E 加入 CI 后再宣称通过。
5. 静态发布零外部 API 依赖，静态资源无404。
6. 任何使用真实数据的看板必须能说明来源、时间与采集方式。
